Procedural Code-Driven Animation

Instead of clunky keyframed tweens, the bear uses continuous mathematical sinusoidal functions in a requestAnimationFrame loop. Every motion is computed directly from elapsed time: pose = f(t).

  • ✓
    Gentle Breathing Bob: y = Math.sin(t * 2.2) * 2.5 creates a natural inhalation and exhalation rhythm.
  • ✓
    Waving Hand: The right arm pivot rotates along the Z and Y axes with Math.sin(t * 4.5) * 16° around the shoulder origin.
  • ✓
    Periodic Eye Blinking: Every 3.6 seconds, the eye meshes squash vertically down to 0.05 scale for 160ms and spring back up smoothly.
  • ✓
    Head Nod & Tilt: Slight organic phase-offset head tilting gives the bear an inquisitive, friendly personality.
JavaScript • Procedural Motion Loop 
function tick(now) {
  const t = (now - t0) / 1000;

  // 1. Gentle breathing bob
  const bob = Math.sin(t * 2.2) * 2.5;
  spline.updateObject(bearId, { position: { y: bob } });

  // 2. Waving right arm
  const wave = Math.sin(t * 4.5) * 16;
  spline.updateObject(armRightId, { rotation: { z: wave } });

  // 3. Cute Eye Blink (every 3.6s for 160ms)
  const blinkT = t % 3.6;
  let scaleY = 1.0;
  if (blinkT < 0.16) {
    scaleY = Math.max(0.05, Math.abs((blinkT / 0.16) - 0.5) * 2);
  }
  spline.updateObject(eyeLeftId, { scale: { y: scaleY } });
  spline.updateObject(eyeRightId, { scale: { y: scaleY } });

  requestAnimationFrame(tick);
}

Smooth Mouse Tracking & Damping

When the user moves the mouse across the screen, the bear naturally turns its body and head toward the cursor without jerky snapping.

  • ✓
    Normalized Coordinates: Screen cursor positions are converted to a -1.0 to +1.0 range relative to viewport center.
  • ✓
    Linear Interpolation (Lerp): The current rotation smoothly glides toward the target rotation with a damping factor of 0.06.
  • ✓
    Safe Clamped Angles: Horizontal rotation is mapped to ±18° and vertical pitch to ±10° so the character remains grounded.
JavaScript • Springy Mouse Parallax 
// Track normalized cursor position
window.addEventListener('pointermove', (e) => {
  mouseTargetX = ((e.clientX / window.innerWidth) - 0.5) * 2;
  mouseTargetY = ((e.clientY / window.innerHeight) - 0.5) * 2;
});

// Inside tick loop: spring lerp
curX += (mouseTargetX - curX) * 0.06;
curY += (mouseTargetY - curY) * 0.06;

// Rotate character body

Natural Walking Cycle & Keyboard Integration

The walking system coordinates alternating bipedal leg swings, opposing arm swings, up-and-down body bounce, and real-time 3D translation along the bear's orientation vector.

  • ✓
    Alternating Leg Strides: Leg Left Pivot and Leg Right Pivot rotate in exact opposition: pitch = ±sin(walkPhase) * 26°.
  • ✓
    Arm Stride & Wave Blending: While walking, arms swing in counter-balance to the legs. As the bear stops, the right arm smoothly returns to its cheerful wave.
  • ✓
    Gentle Walking Bounce: A natural two-bounce-per-stride vertical movement: y = |sin(walkPhase)| * 5.5px plus subtle lateral weight shift.
  • ✓
    3D Heading Translation: Pressing W or S translates along sin(facingAngle) and cos(facingAngle); A and D turn left and right smoothly at 120°/s.
  • ✓
    Smooth Transitions: A walkBlend factor (0.0 to 1.0) with exponential damping ensures no sudden snaps between walking and resting.

JavaScript • Collision Pushout & Follow Camera 
// 1. Tree & Rock Obstacle Collision Resolution
const obstacles = [
  { x: -260, z: -190, radius: 48 }, // Tree 1
  { x:  290, z: -210, radius: 48 }, // Tree 2
  { x: -150, z:  190, radius: 42 }  // Rock 1
];

obstacles.forEach(obs => {
  const dx = bearPosX - obs.x;
  const dz = bearPosZ - obs.z;
  const dist = Math.sqrt(dx * dx + dz * dz);
  const minDist = obs.radius + 35; // Bear collider radius

  if (dist < minDist && dist > 0.001) {
    // Push out along collision normal (smooth slide)
    bearPosX = obs.x + (dx / dist) * minDist;
    bearPosZ = obs.z + (dz / dist) * minDist;
  }
});

// 2. Playable Meadow Perimeter Clamping
const distFromCenter = Math.sqrt(bearPosX * bearPosX + bearPosZ * bearPosZ);
if (distFromCenter > 960) {
  bearPosX = (bearPosX / distFromCenter) * 960;
  bearPosZ = (bearPosZ / distFromCenter) * 960;
}

// 3. Smooth Third-Person Chase Camera Follow
camX += (bearPosX - camX) * 0.06;
camZ += ((bearPosZ + 760) - camZ) * 0.06;
spline.updateObject(camId, {
  position: { x: camX, y: 360, z: camZ }
});

// 2. Procedural WebAudio Two-Tone Chime
function playCoinSound() {
  const t = audioCtx.currentTime;
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();
  osc.type = 'triangle';
  osc.frequency.setValueAtTime(987.77, t);        // B5
  osc.frequency.setValueAtTime(1318.51, t + 0.08); // E6
  gain.gain.setValueAtTime(0.22, t);
  gain.gain.exponentialRampToValueAtTime(0.001, t + 0.32);
  osc.connect(gain).connect(audioCtx.destination);
  osc.start(t); osc.stop(t + 0.34);
}
