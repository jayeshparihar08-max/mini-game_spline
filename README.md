# 🐻 Cute 3D Bear-Man Forest Adventure - Coin Mission

An interactive 3D web mini-game featuring a cute Bear-Man character built with **Spline** and **Vite**.

## 🎮 Features
- **Interactive 3D Character**: Real-time Spline 3D scene integration with camera controls and responsive animations.
- **Coin Collection Mission**: Engaging mini-game mechanics and missions.
- **Modern Responsive UI**: Clean glassmorphism styling and mobile-friendly design.
- **Sound & Effects**: Audio feedback and visual particle effects.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/jayeshparihar08-max/mini-game_spline.git
cd mini-game_spline

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Build for Production
```bash
npm run build
npm run preview
```

## 🛠️ Built With
- [Spline](https://spline.design/) - 3D design and interactive runtime (`@splinetool/viewer`)
- [Vite](https://vitejs.dev/) - Frontend build tooling
- Vanilla HTML5 / CSS3 / JavaScript
